# Design system
Reference: generated desktop concept (1536 × 1046), supplied in handoff outputs.
White header and cards; #f6f8fa canvas; #142d3a navy; #087f8c teal; #eaf7f7 selected surfaces; #dfe7ec borders.
Heebo: h1 40/1.25 bold, h2 22, content 15/1.7, metadata 12–13. Controls 14, minimum target 44px. 12px card radius; shadows only on menus.
1160px centered content, 760px feed / 310px left rail, 24px gap. On mobile one column, sticky bottom navigation.
Native lucide 18–22px outline icons; animal avatar atlas; textual team initials (no licensed team logos).
Feed, ranking table, public profile, recommendation audit, 5-step publishing wizard, notification inbox, profile/account settings, signup/onboarding, legal pages and admin forms use this system.
Intentional corrections to generated concept: no comments (out of scope); no team trademark artwork; only football/basketball (MVP); exact Jerusalem timestamps; real calculated sample data, no invented metrics; explicit event kickoff; additional required league/status/date filters.

User-approved direction change: replaced naturalistic animals with original 2D cartoon streetwear portraits. Wolf has backwards cap, eagle sunglasses/leather, lion fedora/suit/cigar; all 20 have distinct costumes. The avatar atlas was regenerated, not approximated with CSS.
